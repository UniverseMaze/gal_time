GameTime · 游戏计时器 使用说明
================================

一、怎么启动
------------
双击「启动游戏计时器.vbs」，会弹出一个独立的应用窗口（没有地址栏和标签页），
就像普通桌面软件一样。

· 双击后没有任何反应？ 改用「启动游戏计时器（备用）.bat」，它会弹出一次黑色命令窗口后打开程序（窗口会自动关闭）。
· 想让它更像一个软件：程序打开后，在任务栏图标上点右键 →「固定到任务栏」，
  以后点任务栏图标就能直接打开。
· 想放到桌面：右键「启动游戏计时器.vbs」→ 发送到 → 桌面快捷方式；
  想换图标就右键快捷方式 → 属性 → 更改图标 → 选择本文件夹里的 app.ico。


二、功能
--------
【计时】
  1. 左上角「当前游戏」选择一个游戏（没有就点「＋ 新游戏」新建）。
  2. 点「开始计时」开始。
  3. 中途可以随时「暂停」，暂停期间不计时，按「继续」接着算。
  4. 点「结束并保存」，这次时长会写入该游戏的总记录。
  5. 键盘空格键 = 开始 / 暂停，不用鼠标。

  同一个游戏下次再玩时，直接从游戏库点「继续计时」，或者选它再开始，
  时长会自动累加，不会覆盖之前的记录。

【游戏库】
  这里列出你玩过的所有游戏：封面、评分、整体时长、记录段数、最近游玩时间。
  右上角的「卡片 / 列表」开关可以换显示风格（本次新增）：
    · 卡片：封面大图，一屏看几款，适合封面收集得比较齐的库。
    · 列表：一行一款，左边封面缩略图，右边名称、评分、时长、评论摘要，
            一屏能看十几款，游戏多了更好找。
  选的风格会记住，下次打开还是它。
  可以搜索、按「最近游玩 / 整体时长 / 评分 / 完成日期 / 名称」排序。
  没有封面时会用游戏名首字生成彩色底图。
  每张卡片左上角有一个状态标记（本次新增，按你的记录自动算出来的）：
    · ✓ 已完成 月/日 —— 填了完成日期，括号里是那一天
    · ◷ 游戏中       —— 还没填完成日期，但已经有时长记录（计时或补录都算）
    · 未开始         —— 既没完成日期，也一分钟都没记过
  状态不用手动选，填了完成日期就变「已完成」，删光记录就回到「未开始」。
  右上角的「★ 8」是你的评分，没打分时显示「未评分」；写过评论的游戏，
  卡片上还会露出一小段评论摘要。

  卡片上还会显示标签（本次新增）：蓝色圆角小条，最多露 3 个，
  多出来的折成「+N」，鼠标放上去能看到全部标签。
  标签在详情页的「游戏信息」里添加和删除。

  搜索框（本次增强）能搜到：
    · 游戏名
    · 评论正文里的字
    · 标签名（搜「魂系」就把带这个标签的游戏都列出来）
    · 游戏信息里的字（发行、剧本、原画、开发、平台、游戏类型、简介…）
      比如搜「FromSoftware」「视觉小说」「KiriKiri」都能命中。

  点任意一张卡片 / 任意一行（或点卡片上的「详情」按钮），就会进入这款游戏的
  详情页，见下一节。想直接开始玩，点卡片上的「继续计时」。

  点「＋ 添加游戏」新建之后，会留在游戏库页面（不会跳去计时页），
  新卡片会闪一下标出来，方便你接着给它选封面、打分、写评论。

【游戏详情页（本次新增）】
  游戏库里的每一款游戏都有自己的详情页，从头到尾一整页，比原来的弹窗宽很多，
  写长评论更舒服。右上角「← 返回游戏库」回去；侧栏「游戏库」也一直是亮的。

  从上到下依次是：
  · 顶部信息块
      - 封面：点「选择封面图片」挑本机 jpg/png/webp，会自动压缩后保存；
              计时页还会把它做成背景氛围。「移除封面」可以去掉。
      - 名称：改完点「保存名称」（或直接回车）。
      - 「继续计时」：马上跳到计时页并选中这款游戏。
      - 标签：评分、状态（已完成 / 游戏中 / 未开始）、是否正在计时、评论字数。
      - 四个数字：整体游戏时间、分段记录段数、最长单次、完成日期。
      - 「删除游戏」会连记录一起删掉，删完自动回到游戏库。

  · 游戏信息（本次新增）
      顶部信息块下面的一整张卡，用来存这部作品的「资料」和「标签」。

      展示时是一张资料表，从上到下：
        发行 / 剧本 / 原画 / 背景 / 别名 / 平台 / 游戏类型 /
        游戏引擎 / 游玩人数 / 发行日期 / 售价 / 开发
      平台会显示成一个个圆角小标签（PC、Nintendo Switch…）。
      没填的项显示「—」，不会留下空白让人以为出错。
      最下面是「游戏简介」，支持多行。

      点右上角「编辑信息」进入编辑：
        - 两列表单，别名、平台、简介占整行；
        - 别名和售价可以写多行（比如不同平台不同价，一行一个）；
        - 平台一栏用逗号或顿号分隔，比如「PC、Nintendo Switch」，
          保存后自动拆成多个小标签；
        - 改完点「保存信息」，点「取消」则丢弃这次修改。

      这些字段可以不用手打：项目里带了一套 Bangumi 同步脚本
      （tools/bgm_login_crawl.py + tools/match_local.py），按你的 Bangumi
      收藏一次性把发行、剧本、原画、平台、售价、简介和标签填进来。
      用法写在 README 的「从 Bangumi 同步作品信息」一节。
      填充只写「游戏信息」和「标签」，计时、评分、评论、分段记录不受影响。

      〖标签〗
      卡片最底部是标签区，**不需要点编辑，直接就能增删**：
        · 添加：在右边的输入框写一个词，按回车即可。
                点到别处时如果框里还有字，也会顺手加上。
        · 删除：点标签上的 ×，立刻生效。
        · 最多 30 个标签，每个最长 20 字；同名标签（不分大小写、
          前后空格）不会重复添加。

      标签是给搜索用的：游戏库搜索框、统计页的搜索和标签下拉，
      都是按标签找游戏的依据。

  · 评分
      10 个数字按钮，1 分最差、10 分满分，点一下就是那个分数，
      右边会显示「8 分 / 10 · 值得一玩」。再点一次当前分数 = 清除评分。

  · 长评论（Markdown 编辑器）
      一块带工具栏的 Markdown 编辑框，左边写、右边实时排版预览，
      想写多长写多长（上限 5000 字）。
      - 右上角三个模式：「编辑」只看输入框、「分屏」左右对照（默认）、
        「预览」只看排版效果。选过一次会记住，下次打开还是那个模式。
      - 工具栏从左到右：加粗 B、斜体 I、删除线 S、标题 H、无序列表、
        有序列表、引用 ❝、行内代码 ` `、代码块 { }、链接、分隔线 —。
        选中文字再点按钮，就会给这段文字套上语法；再点一次同样的按钮取消。
        列表 / 引用 / 标题是按行加前缀的，选中多行可以一次全加上。
      - 快捷键：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+K 链接、Tab 缩进两格、
        Ctrl+Enter 立刻保存。
      - 支持这些语法：
          # 一级标题   ## 二级标题   ### 三级标题
          **加粗**   *斜体*   ~~删除线~~   `行内代码`
          - 无序列表      1. 有序列表      - [x] 已完成的任务
          > 引用            ``` 代码块 ```          --- 分隔线
          [文字](https://网址)   直接粘贴网址也会自动变成链接
        空行分段；单个换行按原样换行显示（所以老版本写的纯文本评论不会乱）。
      - 打字停手约 1 秒会自动保存，按钮右边会显示「已自动保存 时:分」；
        还在输入没存时显示橙色的「未保存…」。
      - 也可以点「保存评分与评论」立刻保存。
      - 返回游戏库、切到别的页面、关闭窗口之前，都会自动把没保存的评论存一次。
      - 右下角有字数统计「328 / 5000」。
      评论按 Markdown 原文保存，游戏库卡片 / 列表上的摘要会自动去掉语法符号，
      只显示纯文字，不会满屏 ** 和 #。
      评分和评论都跟着游戏走，删掉游戏才会一起删掉。

  · 整体记录
      - 整体游戏时间：直接填这款游戏的总时长（时 / 分）。比如 Steam 显示
        你玩了 120 小时，直接填 120 就行，不用一段段补。
      - 完成日期：选通关的日期；点「清除」表示还没通关（状态会退回到「游戏中」）。
      - 填完点「保存整体记录」。两个字段分开生效，只改一个不会影响另一个。

    这两项和分段记录是两条互不干扰的账：
      「整体游戏时间」=「分段记录合计」+「手动记录的部分」
      填的整体时间比分段合计多，多出来的部分会记成一条「手动记录」，
      显示在分段记录列表最上面（标注「不计入分段」）。
      分段记录一条都不会被改动、被合并、被删掉。

      如果填的整体时间比分段合计还小，程序不会去砍你的记录，
      而是保留分段合计作为最小值，并提示你「整体时间不能比它更小」；
      真要减少，请编辑或删除下面的具体记录。

  · 分段记录
      每条都是真实计时或补录出来的一段：
      - 铅笔图标 ✎ 改这一段：游玩日期时间（可改成过去任意一天）+ 时长（时/分/秒）
      - ✕ 删除这一条
      - 「＋ 补录一段」：手动补记以前玩过的某天某段时长

  之后再用这个游戏计时，新时长会加进分段记录，「手动记录」的部分保持不变，
  整体时间照旧一起增长。

【统计】
  最上面是一张「数据汇总」卡（本次改版），筛选控件移到了这张卡里：
    · 搜索框：和游戏库一样，能搜游戏名 / 标签 / 评论 / 游戏信息。
    · 标签下拉：列出库里用过的所有标签，括号里是带这个标签的款数。
    · 状态下拉：全部游戏 / 只看已完成 / 只看游戏中 / 只看未开始 /
                8 分及以上 / 只看未评分
    · 「重置筛选」：一键把上面三项都清掉。

  ★ 下面这些都会跟着筛选变（本次新增）：
    - 整体游戏时长、游戏数量、游戏状态（已完成 / 游戏中 / 未开始）、
      平均评分、今日时长、最长单次；
    - 最近 7 天柱状图、评分占比环状图；
    - 排行榜里的条目和右上角的条数。
    卡片右上角写着范围：「全部 7 款游戏」或「筛选出 3 款 / 共 7 款」，
    一眼能看出当前的数字是什么口径。

  ★ 不跟着变的是分页：换页、改每页条数只影响列表显示几行，
    汇总数字、两张图表都不动——数字始终按「筛选后的全部游戏」算，
    而不是按当前这一页算。

  最近 7 天柱状图：补录和手动调整的记录也会按你填的日期算进来；
  手动填写的「整体游戏时间」计入总时长和排行，但没有具体日期，
  所以不会出现在这张图里。

  评分占比环状图：
    右边的圆环把当前筛选出的游戏按评分拆开，每一段是一种分数，
    灰色那段是「未评分」。圆环中间是这些游戏的平均分，
    下面写着「已评分 5 / 7」。右侧图例逐行列出：颜色、几分、几款、百分比。
    分数越高颜色越暖（10 分是金色），越低越偏冷；相邻分数还会错开亮暗，
    挨在一起的两段也能分清。鼠标放在图例行上会显示完整的说明。
    没有筛选时就是整个库的评分分布。

  下面的「游戏排行」右上角只剩两个下拉框（筛选已经移到上面的汇总卡）：
  · 排序：按整体时长 / 按分数 / 按完成日期 / 按名称
        「按分数」是高分在前，没打分的游戏排在最后，金色进度条是分数占比。
  · 每页条数：5 / 8 / 10 / 20 / 50 条，或者「全部显示」。
        游戏多的时候一页一页翻，不会拉得很长。
        列表下面有「上一页 / 页码 / 下一页」，并显示「共 N 条 · 第 1 / 2 页」，
        页码中间用省略号收起来，页数很多也不会挤成一排。
  排序、每页条数、状态筛选、标签筛选都会记住，下次打开还是你上次选的
  （搜索框里的字不会记，重开是空的，免得一进来看到的是筛选后的列表）。
  （如果你之前选的是「只看已评分」，升级后会回到「全部游戏」。）

  时间条的比例（本次调整）：
  以前进度条是「这款游戏 ÷ 所有游戏总时长」，游戏一多，每条都短得像小短线。
  现在改成以「本页最长时间」为满格来画，最长的那款一定铺满，
  其余按比例跟着缩短；如果页内长短差得太夸张（最短不到最长的 12%），
  会自动做一次轻微压缩，让小体量的游戏也看得见，排序顺序不会变。
  把鼠标放在进度条上，会显示它相当于本页最长时间的百分之多少。

  排行里每行右侧同时显示分数和整体时长，方便对照「高分是不是也玩得久」。

【自动恢复】
  如果计时过程中直接关掉了窗口，下次打开会自动恢复为「已暂停」，
  时长不丢，可以继续或者直接保存。进度最多只会丢 1 秒。


三、数据存在哪里 / 怎么备份
--------------------------
· 数据保存在本文件夹的 profile 目录里（不联网、不上传）。
  整个 GameTime 文件夹复制到别的电脑，数据一起带走，可以直接接着用。
· 浏览器里常规的「清除浏览数据」不会影响这个程序的数据。
· 建议偶尔点左下角「导出备份」，会下载一个 json 文件；
  换电脑或误删后，用「导入备份」恢复。
· 你的记录在 profile\Default\Local Storage 里。profile 其余部分是浏览器自身的缓存，
  可以清理：完全关掉程序后，删掉 profile 里除 Default 以外的文件夹即可回收空间
  （清之前建议先「导出备份」）。启动器已经关掉了后台组件下载与同步，
  所以正常情况下这个目录占用很小。
· 清理前请先完全关闭程序窗口。程序还开着的时候动 profile 目录，
  浏览器可能拒绝后续写入，这时手动保存会失败（数据本身不会坏，
  关掉程序重新打开就好，或者点顶部提示条里的「重试保存」）。


四、小提示
----------
· 计时期间程序会尽量阻止屏幕自动休眠，避免挂机时中断。
· 窗口最小化也照常计时（按真实时间计算），可以放心去玩。
· 想换浅色界面：左下角「切换明暗主题」。
· 封面的体积会算进本地存储（这个程序能用的上限大约 5 MB，每张封面几十 KB）。
  左下角会显示「本地占用 xx KB / 约 5 MB」，可以随时看还剩多少。
· 如果保存失败，界面顶部会出现一条红色提示（不会一闪而过），
  上面有「重试保存」和「导出备份」两个按钮：
  先点「导出备份」把记录存成 json，再点「重试保存」。
  程序也会自动重试几次，存储后端卡住时会自动重建后写回。
  注意：保存失败时新加的记录只存在于窗口里，关掉窗口就没了，
  所以看到提示请先导出备份。
